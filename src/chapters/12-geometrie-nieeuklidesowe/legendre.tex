\subsection{Adrien-Marie Legendre} % lang-pl
\subsection{Adrien-Marie Legendre} % lang-it
\label{sekcja_legendre}

Trzecią osobą, która zaatakuje problem prawdziwości piątego postulatu przez sprowadzenie do niedorzeczności jego alternatyw, będzie Adrien-Marie Legendre. % lang-pl
Rozpatrzy trzy możliwości: % lang-pl
La terza persona ad attaccare il problema della verità del quinto postulato riducendo all'assurdo le sue alternative sarà Adrien-Marie Legendre. % lang-it
Prenderà in esame tre possibilità: % lang-it
\begin{itemize}
    \item suma kątów trójkąta jest większa od $\pi$, % lang-pl
    \item suma kątów trójkąta jest równa $\pi$, % lang-pl
    \item suma kątów trójkąta jest mniejsza od $\pi$. % lang-pl
    \item la somma degli angoli di un triangolo è maggiore di $\pi$, % lang-it
    \item la somma degli angoli di un triangolo è uguale a $\pi$, % lang-it
    \item la somma degli angoli di un triangolo è minore di $\pi$. % lang-it
\end{itemize}
(Odpowiada to hipotezom Saccheriego, w tej samej kolejności). % lang-pl
Legendre, tak jak Saccheri i Lambert, milcząco założy, że proste są nieskończone i wyeliminuje pierwszą możliwość, ale nie poradzi sobie z trzecią. % lang-pl
(Ciò corrisponde alle ipotesi di Saccheri, nello stesso ordine). % lang-it
Legendre, come Saccheri e Lambert, assumerà tacitamente che le rette siano infinite ed eliminerà la prima possibilità, ma non riuscirà a venire a capo della terza. % lang-it

\begin{proposition}
[aksjomat Legendre'a] % lang-pl
[assioma di Legendre] % lang-it
    Przez każdy punkt wewnątrz kąta można przeprowadzić prostą, która przecina obydwa ramiona kąta. % lang-pl
    Per ogni punto interno a un angolo si può tracciare una retta che interseca entrambi i lati dell'angolo. % lang-it
\end{proposition}

Ne scrivono Hartshorne \cite[p. 322]{hartshorne_2000} ed Eves \cite[p. 286, 290]{eves1_1972}. % lang-it
