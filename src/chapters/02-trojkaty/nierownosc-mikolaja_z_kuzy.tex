\subsection{Nierówność Mikołaja z Kuzy} % lang-pl
\subsection{Disuguaglianza di Niccolò Cusano} % lang-it

\index{nierówność!Mikołaja z Kuzy} % lang-pl
\index{disuguaglianza!di Niccolò Cusano} % lang-it

Mikołaj z Kuzy odkryje wzmocnienie nierówności $\frac{\sin x} x < 1$ na podstawie rozważań geometrycznych, tak jak opisze to Guzicki \cite[s. 390]{guzicki_2021}: % lang-pl
Niccolò Cusano scoprì un rafforzamento della disuguaglianza $\frac{\sin x} x < 1$ sulla base di considerazioni geometriche, come descritto da Guzicki \cite[p. 390]{guzicki_2021}: % lang-it

\begin{proposition}
[nierówność Mikołaja z Kuzy] % lang-pl
[disuguaglianza di Niccolò Cusano] % lang-it
    Jeśli $x \in (0, \pi/2)$, to % lang-pl
    Se $x \in (0, \pi/2)$, allora % lang-it
\begin{equation}
    \label{nierownosc_mikolaja_z_kuzy}
    \frac{\sin x}{x} < \frac{2 + \cos x}{3}.
\end{equation}
\end{proposition}

Z opisaną nierównością sąsiaduje pokrewny wynik dla średniej arytmetycznej sinusa i tangensa, który elementarnie -- bez rachunku różniczkowego -- udowodni Wojciech Wilhelm Wdowik w $\Delta_{20}^3$: dla każdego kąta ostrego $\theta$ zachodzi $2\theta < \sin \theta + \tan \theta$. % lang-pl
Alla disuguaglianza descritta si affianca un risultato affine per la media aritmetica di seno e tangente, che Wojciech Wilhelm Wdowik dimostrerà elementarmente -- senza calcolo differenziale -- in $\Delta_{20}^3$: per ogni angolo acuto $\theta$ vale $2\theta < \sin \theta + \tan \theta$. % lang-it
