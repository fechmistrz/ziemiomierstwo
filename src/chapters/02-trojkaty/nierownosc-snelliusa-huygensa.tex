\subsection{Nierówność Snelliusa-Huygensa} % lang-pl
\subsection{Disuguaglianza di Snellius-Huygens} % lang-it

\index{nierówność!Snelliusa-Huygensa}% % lang-pl
\index{disuguaglianza!di Snellius-Huygens}% % lang-it
\begin{proposition}
[nierówność Snelliusa-Huygensa]
[disuguaglianza di Snellius-Huygens]
    Jeśli $x \in (0, \pi/2)$, to % lang-pl
    Se $x \in (0, \pi/2)$, allora % lang-it
    \begin{equation}
        2 \sin x + \tan x > 3x.
        \label{nierownosc_snelliusa}
    \end{equation}
\end{proposition}

Willebrod Snellius poda zawiły dowód w książce Cyclometicus (1631); schludniejsze uzasadnienie znajdzie Christian Huygens. % lang-pl
Willebrod Snellius fornirà una dimostrazione piuttosto elaborata nel libro \emph{Cyclometicus} (1631); una giustificazione più elegante sarà trovata da Christian Huygens. % lang-it
\index[persons]{Snellius, Willebrod}%

W \emph{,,De circuli magnitudine inventa''} użyje nierówności \ref{nierownosc_mikolaja_z_kuzy} oraz \ref{nierownosc_snelliusa} do oszacowania wartości $\pi$. % lang-pl
In \emph{De circuli magnitudine inventa} utilizzerà le disuguaglianze \ref{nierownosc_mikolaja_z_kuzy} e \ref{nierownosc_snelliusa} per stimare il valore di $\pi$. % lang-it

Guzicki \cite[s. 391]{guzicki_2021} zróżniczkuje $2 \sin x + \tan x - 3x$ i stwierdzi, że to wyrażenie jest dodatnie. % lang-pl
Guzicki \cite[p. 391]{guzicki_2021} differenzierà l'espressione $2 \sin x + \tan x - 3x$ e constaterà che essa è positiva. % lang-it
Ale poda też prostszy dowód słabszej nierówności $\sin x + \tan x > 2x$. % lang-pl
Fornirà però anche una dimostrazione più semplice della più debole disuguaglianza $\sin x + \tan x > 2x$. % lang-it
