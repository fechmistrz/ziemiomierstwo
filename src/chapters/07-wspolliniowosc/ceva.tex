Ważnym kryterium współpękowości trzech czewian jest: % lang-pl
Un importante criterio di concorrenza di tre ceviane è il seguente: % lang-it

\begin{theorem}[Cevy]
\index{twierdzenie!Cevy} % lang-pl
\index{teorema!di Ceva} % lang-it
\label{twierdzenie_cevy}%
    Dany jest trójkąt $ABC$ i trzy różne od wierzchołków punkty $K \in BC$, $L \in CA$, $M \in AB$. % lang-pl
    Wówczas czewiany $AK$, $BL$, $CM$ są współpękowe wtedy i tylko wtedy, gdy % lang-pl
    Siano dati un triangolo $ABC$ e tre punti distinti dai vertici: $K \in BC$, $L \in CA$, $M \in AB$. % lang-it
    Allora le ceviane $AK$, $BL$, $CM$ sono concorrenti se e solo se % lang-it
    \begin{equation}
        [AMB] [BKC] [CLA] = 1.
    \end{equation}
\end{theorem}

Wnioskiem z twierdzenia Cevy jest wynik znany jako lemat Steinbarta: % lang-pl
Una conseguenza del teorema di Ceva è il risultato noto come lemma di Steinbart: % lang-it

\begin{lemma}
[Steinbarta]% lang-pl
[di Steinbart]% lang-it
    W trójkąt $ABC$ wpisano okrąg, styczny do boków $BC$, $AC$ i $AB$ kolejno w punktach $D$, $E$, $F$. % lang-pl
    Punkty $X$, $Y$, $Z$ leżą odpowiednio na krótszych łukach $EF$, $FD$ i $DE$. % lang-pl
    Następujące warunki są równoważne: % lang-pl
    %
    In un triangolo $ABC$ è inscritta una circonferenza tangente ai lati $BC$, $AC$ e $AB$ rispettivamente nei punti $D$, $E$, $F$. % lang-it
    I punti $X$, $Y$, $Z$ appartengono rispettivamente agli archi minori $EF$, $FD$ e $DE$. % lang-it
    Le seguenti condizioni sono equivalenti: % lang-it
    \begin{itemize}
        \item proste $XD$, $YE$, $ZF$ są współpękowe, % lang-pl
        \item proste $AX$, $BY$, $CZ$ są współpękowe. % lang-pl
        \item le rette $XD$, $YE$, $ZF$ sono concorrenti, % lang-it
        \item le rette $AX$, $BY$, $CZ$ sono concorrenti. % lang-it
    \end{itemize}
\end{lemma}

Prostą, która przechodzi przez wierzchołek trójkąta i przeciwległy bok nazywa się czewianą, nazwy tej używa się też wobec odcinka trójkąta leżącego na tej prostej. % lang-pl
Una retta che passa per un vertice di un triangolo e il lato opposto è detta ceviana; lo stesso termine viene usato anche per il segmento del triangolo contenuto in tale retta. % lang-it

\begin{proposition}
[wzór Steinera--Routha]% lang-pl
[formula di Steiner--Routh]% lang-it
    Rozpatrzmy trójkąt $ABC$ z czewianami $AD$, $BE$, $CF$ tak, że % lang-pl
    Consideriamo un triangolo $ABC$ con ceviane $AD$, $BE$, $CF$ tali che % lang-it
    \begin{equation}
        \frac{BD}{DC} = \lambda_1, \quad
        \frac{CE}{EA} = \lambda_2, \quad
        \frac{AF}{FB} = \lambda_3.
    \end{equation}
    Oznaczmy przekrój $BE$ i $CF$ przez $G_1$; $AD$ i $CF$ przez $G_2$, zaś $AD$ i $BE$ przez $G_3$. % lang-pl
    Wtedy % lang-pl
    %
    Indichiamo con $G_1$ l'intersezione di $BE$ e $CF$, con $G_2$ quella di $AD$ e $CF$, e con $G_3$ quella di $AD$ e $BE$. % lang-it
    Allora % lang-it
    \begin{equation}
        \frac{S_{G_1G_2G_3}}{S_{ABC}} = \frac{(\lambda_1 \lambda_2 \lambda_3 - 1)^2}{
            (\lambda_1 \lambda_2 + \lambda_1 + 1)
            (\lambda_2 \lambda_3 + \lambda_2 + 1)
            (\lambda_3 \lambda_1 + \lambda_3 + 1)
        }
    \end{equation}
    oraz % lang-pl
    e % lang-it
    \begin{equation}
        \frac{S_{DEF}}{S_{ABC}} = \frac{\lambda_1 \lambda_2 \lambda_3 + 1}{
            (\lambda_1 + 1)
            (\lambda_2 + 1)
            (\lambda_3 + 1)
        }.
    \end{equation}
\end{proposition}
