\begin{definition}
Cztery punkty, z których żadne trzy nie są współliniowe, leżące na sześciu prostych przez sześć par punktów, nazywamy czworokątem zupełnym. % % lang-pl
Quattro punti, di cui nessuno tre sono allineati, situati su sei rette determinate dalle sei coppie di punti, si chiamano quadrilatero completo. % % lang-it
\end{definition}

Sześć prostych wyznacza dodatkowe trzy punkty, które nazywamy przekątniowymi. % % lang-pl
\index{punkty przekątniowe}% % lang-pl
Le sei rette determinano ulteriori tre punti, che chiamiamo punti diagonali. % % lang-it
\index{punti diagonali}% % lang-it

\begin{definition}
Cztery proste, z których żadne trzy nie są współpękowe, przecinające się parami w sześciu różnych punktach, nazywamy czworobokiem zupełnym. % % lang-pl
Quattro rette, di cui nessuna tre concorrenti, che si intersecano a coppie in sei punti distinti, si chiamano quadrilatero completo. % % lang-it
\end{definition}

\begin{theorem}
[Annego] % lang-pl
[di Anne] % lang-it
\index{twierdzenie!Annego}% % lang-pl
Niech $ABCD$ będzie wypukłym czworokątem, ale nie równoległobokiem; z punktami $E$, $F$ na środku przekątnych $BD$, $AC$ oraz punktem $L$ gdziekolwiek wewnątrz. % % lang-pl
Wtedy następujące warunki są równoważne: % % lang-pl
\index{teorema!Anne}% % lang-it
Sia $ABCD$ un quadrilatero convesso, ma non un parallelogramma; con punti $E$, $F$ al centro delle diagonali $BD$, $AC$ e un punto $L$ qualsiasi all'interno. % % lang-it
Allora le seguenti condizioni sono equivalenti: % % lang-it
\begin{itemize}
	\item $|\triangle_{BCL}| + |\triangle_{DAL}| = |\triangle_{LAB}| + |\triangle_{DLC}|$, % lang-pl
	\item $|\triangle_{BCL}| + |\triangle_{DAL}| = |\triangle_{LAB}| + |\triangle_{DLC}|$, % lang-it
	\item punkt $L$ leży na prostej $EF$. % lang-pl
	\item il punto $L$ giace sulla retta $EF$. % lang-it
\end{itemize}
\end{theorem}

(Twierdzenie udowodni francuski matematyk Pierre-Léon Anne, kiedyś między narodzinami w 1806 roku i śmiercią w 1850 roku). % % lang-pl
(Il teorema fu dimostrato dal matematico francese Pierre-Léon Anne, vissuto tra la nascita nel 1806 e la morte nel 1850). % % lang-it

\begin{theorem}
[Gaussa-Bodenmillera] % lang-pl
[di Gauss-Bodenmiller] % lang-it
\index{twierdzenie!Gaussa-Bodenmillera}% % lang-pl
Trzy okręgi, których średnice stanowią przekątne ustalonego czworoboku zupełnego, są współosiowe. % % lang-pl
\index{teorema!Gauss-Bodenmiller}% % lang-it
Tre cerchi, i cui diametri sono le diagonali di un quadrilatero completo dato, sono coassiali. % % lang-it

Ich wspólna oś potęgowa przechodzi przez ortocentra czterech trójkątów wyznaczonych przez boki czworoboku. % % lang-pl
Il loro asse radicale comune passa per gli ortocentri dei quattro triangoli determinati dai lati del quadrilatero. % % lang-it
% https://mathworld.wolfram.com/Gauss-BodenmillerTheorem.html - dla niektórych twierdzenie składa się tylko z pierwszego zdania.
\end{theorem}
