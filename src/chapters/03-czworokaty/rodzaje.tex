\begin{definition}[czworokąt] % lang-pl
\index{czworokąt}% % lang-pl
Dane są cztery punkty $A$, $B$, $C$, $D$, z których żadne trzy nie są współliniowe, takimi że odcinki $AB$, $BC$, $CD$, $DA$ nie mają części wspólnej poza końcami. % % lang-pl
Wtedy sumę tych odcinków nazywamy czworokątem. % % lang-pl
\begin{definition}[quadrilatero] % lang-it
\index{quadrilatero}% % lang-it
Sono dati quattro punti $A$, $B$, $C$, $D$, tali che nessuno tre di essi siano allineati e tali che i segmenti $AB$, $BC$, $CD$, $DA$ non abbiano parti in comune se non agli estremi. % % lang-it
Allora l’unione di questi segmenti si chiama quadrilatero. % % lang-it
\end{definition}

Po angielsku \emph{quadrangle}, z łacińskiego \emph{quadri} określającego liczbę cztery oraz \emph{latus}, czyli boku (a~więc technicznie czworobok, nie czworokąt); istnieje też rzadko używane słowo \emph{tetragon} (przez analogię do \emph{polygon, pentagon}) z greckiego \emph{tetra} (cztery) oraz \emph{gon} (znaczącego tym razem kąt). % % lang-pl
Niektórzy dopuszczają czworokąty z samoprzecięciem, nazywając je muchą lub motylem. % % lang-pl
\index{motyl}% % lang-pl
\index{mucha}% % lang-pl
Hartshorne \cite[s.~80]{hartshorne2000} nie akceptuje motyli. % % lang-pl
In inglese \emph{quadrangle}, dal latino \emph{quadri} (quattro) e \emph{latus} (lato) (quindi tecnicamente ``quadrilatero'', non ``quadrangolo''); esiste anche il termine meno comune \emph{tetragon} (per analogia con \emph{polygon, pentagon}), dal greco \emph{tetra} (quattro) e \emph{gon} (che qui significa angolo). % % lang-it
Alcuni ammettono quadrilateri auto-intersecanti, chiamandoli mosca o farfalla. % % lang-it
\index{farfalla}% % lang-it
\index{mosca}% % lang-it
Hartshorne \cite[p.~80]{hartshorne2000} non accetta le ``farfalle''. % % lang-it

Czworokąty, które nie mają samoprzecięć, mogą być wypukłe albo wklęsłe. % % lang-pl
Wypukłe tworzą bogatszą rodzinę. % % lang-pl
W krajach anglosaskich wyróżnia się czworokąty nieregularne, które nie mają żadnej pary boków równoległych (\emph{trapezium} w amerykańskiej odmianie języka). % % lang-pl
I quadrilateri che non hanno auto-intersezioni possono essere convessi oppure concavi. % % lang-it
Quelli convessi formano una famiglia più ricca. % % lang-it
Nei paesi anglosassoni si distinguono i quadrilateri irregolari, che non hanno alcuna coppia di lati paralleli (\emph{trapezium} nella variante americana dell’inglese). % % lang-it

\begin{definition}[trapez] % lang-pl
\index{trapez}% % lang-pl
Czworokąt, który posiada jedną lub dwie pary boków równoległych nazywamy trapezem. % % lang-pl
\begin{definition}[trapezio] % lang-it
\index{trapezio}% % lang-it
Un quadrilatero che possiede una o due coppie di lati paralleli si chiama trapezio. % % lang-it
\end{definition}

Po brytyjsku \emph{trapezium}, po amerykańsku \emph{trapezoid} --- widać więc kolizję z terminem na czworokąt ,,w~ogólnym położeniu''. % lang-pl
Wyjaśnimy to po podaniu pozostałych definicji. % % lang-pl
In inglese britannico \emph{trapezium}, in quello americano \emph{trapezoid} -- si vede quindi una collisione con il termine per un quadrilatero ``in posizione generale''. % % lang-it
Lo chiariremo dopo aver dato le altre definizioni. % % lang-it

\begin{definition}[trapez równoramienny] % lang-pl
\index{trapez!równoramienny}% % lang-pl
Czworokąt, który posiada parę boków równoległych, którego kąty przy podstawie są równej miary, nazywamy trapezem równoramiennym. % % lang-pl
\begin{definition}[trapezio isoscele] % lang-it
\index{trapezio!isoscele}% % lang-it
Un quadrilatero che possiede una coppia di lati paralleli e i cui angoli alla base sono uguali si chiama trapezio isoscele. % % lang-it
\end{definition}

W szczególności, nie można definiować trapezu równoramiennego jako trapezu, który ma ramiona równej długości! % % lang-pl
To czyniłoby wszystkie równoległoboki trapezami równoramiennymi, co nie ma żadnych zalet. % % lang-pl
\index{równoległobok}% % lang-pl
Inne, równoważne definicje mówią, że jest to czworokąt z osią symetrii, która połowi parę przeciwległych boków albo trapez, który ma przekątne równej długości. % % lang-pl
In particolare, non si può definire un trapezio isoscele come un trapezio con i lati obliqui di uguale lunghezza! % % lang-it
Questo renderebbe tutti i parallelogrammi trapezi isosceli, il che non ha alcun vantaggio. % % lang-it
\index{parallelogramma}% % lang-it
Altre definizioni equivalenti affermano che è un quadrilatero con un asse di simmetria che dimezza una coppia di lati opposti, oppure un trapezio con diagonali di uguale lunghezza. % % lang-it

\begin{definition}[równoległobok] % lang-pl
\index{równoległobok}% % lang-pl
Czworokąt, który posiada dwie pary boków równoległych, nazywamy równoległobokiem. % % lang-pl
\begin{definition}[parallelogramma] % lang-it
\index{parallelogramma}% % lang-it
Un quadrilatero che possiede due coppie di lati paralleli si chiama parallelogramma. % % lang-it
\end{definition}

Każdy równoległobok (po angielsku \emph{parallelogram}) jest też trapezem. % % lang-pl
Alternatywne definicje głoszą, że ma przeciwległe boki równej długości, albo równe przeciwległe kąty, albo połowiące się wzajemnie przekątne (jak pan Pompe opisał \cite[s. 37]{pompe_2022}). % % lang-pl
Ogni parallelogramma (in inglese \emph{parallelogram}) è anche un trapezio. % % lang-it
Definizioni alternative affermano che ha lati opposti di uguale lunghezza, oppure angoli opposti uguali, oppure diagonali che si bisecano (come descritto da Pompe \cite[p. 37]{pompe_2022}). % % lang-it

\begin{definition}[romb] % lang-pl
\index{romb}% % lang-pl
Czworokąt, który posiada cztery boki tej samej długości, nazywamy rombem. % % lang-pl
\begin{definition}[rombo] % lang-it
\index{rombo}% % lang-it
Un quadrilatero con quattro lati della stessa lunghezza si chiama rombo. % % lang-it
\end{definition}

Równoważnie, romby to te czworokąty, których prostopadłe przekątne połowią się i rozcinają romb na cztery przystające trójkąty (prostokątne). % % lang-pl
Angielski nazywa je \emph{rhombus}. % % lang-pl
Equivalentemente, i rombi sono quei quadrilateri le cui diagonali perpendicolari si bisecano e dividono il rombo in quattro triangoli congruenti (rettangoli). % % lang-it
In inglese si chiamano \emph{rhombus}. % % lang-it

\index{prostokąt}% % lang-pl

\begin{definition}[kwadrat] % lang-pl
\index{kwadrat}% % lang-pl
Czworokąt, który posiada cztery kąty tej samej miary i wszystkie boki tej samej długości, nazywamy kwadratem. % % lang-pl
\begin{definition}[quadrato] % lang-it
\index{quadrato}% % lang-it
Un quadrilatero con quattro angoli uguali e tutti i lati della stessa lunghezza si chiama quadrato. % % lang-it
\end{definition}

Kwadraty (\emph{squares}) to dokładnie te prostokąty (\emph{rectangles}), które są równocześnie rombami. % % lang-pl
Pole kwadratu o boku długości $a$ wynosi $a^2$, jego obwód to $4a$, zaś przekątna ma długość $a \sqrt 2$. % % lang-pl
I quadrati (\emph{squares}) sono esattamente quei rettangoli (\emph{rectangles}) che sono anche rombi. % % lang-it
L’area di un quadrato di lato $a$ è $a^2$, il suo perimetro è $4a$ e la diagonale ha lunghezza $a \sqrt 2$. % % lang-it

Czworokąt, który ma dwie pary sąsiednich boków równej długości, nazywamy latawcem. % % lang-pl

W Polsce bardziej popularne będzie określenie deltoid. % % lang-pl
Latawce mają jedną przekątną, która dzieli je na dwa przystające trójkąty, w szczególności jego przekątne są prostopadłe. % % lang-pl
Na latawcu, który ma dwa kąty proste naprzeciw siebie można opisać okrąg. % % lang-pl
Romby są szczególnym przypadkiem latawców. % % lang-pl
In Polonia è più diffuso il termine deltoide. % % lang-it
Gli aquiloni hanno una diagonale che li divide in due triangoli congruenti; in particolare le loro diagonali sono perpendicolari. % % lang-it
Su un aquilone che ha due angoli retti opposti si può costruire un cerchio circoscritto. % % lang-it
I rombi sono un caso particolare di aquiloni. % % lang-it

Czworokąty wklęsłe mają jeden kąt, którego miara wynosi między $\pi$ i $2\pi$ radianów. % % lang-pl
Wyróżniamy wśród nich rzutki (z angielskiego \emph{dart, arrowhead}), które mają oś symetrii albo równoważnie, dwie pary sąsiednich boków równej długości, tak jak latawce. % % lang-pl
\index{rzutka}% % lang-pl
I quadrilateri concavi hanno un angolo la cui misura è compresa tra $\pi$ e $2\pi$ radianti. % % lang-it
Tra essi distinguiamo i dardi (in inglese \emph{dart, arrowhead}), che hanno un asse di simmetria oppure, equivalentemente, due coppie di lati consecutivi di uguale lunghezza, come gli aquiloni. % % lang-it

W starożytnej Grecji czworokąty podzieli się na rozłączne klasy: kwadraty, podłużne prostokąty (po angielsku \emph{oblong}), niekwadratowe romby, romboidy (równoległoboki, które nie są ani rombami, ani prostokątami) oraz \emph{trapezia} (τραπέζιον znaczy dosłownie stolik), które nie pasowały do wcześniej wymienionych. % % lang-pl
Filozof neoplatoński Proklos zwany Diadochem napisze wpływowy komentarz do prac Euklidesa, gdzie wprowadzi trochę inny podział zgodnie z tym, co obmyśli około 100 lat p.n.e. Posejdonios z Rodos (nauczyciel Cycerona). % % lang-pl
Nell’antica Grecia i quadrilateri venivano suddivisi in classi disgiunte: quadrati, rettangoli allungati (in inglese \emph{oblong}), rombi non quadrati, romboidi (parallelogrammi che non sono né rombi né rettangoli) e \emph{trapezia} (τραπέζιον significa letteralmente ``tavolino''), che non rientravano nelle categorie precedenti. % % lang-it
Il filosofo neoplatonico Proclo, detto il Diadoco, scriverà un influente commento alle opere di Euclide, introducendo una classificazione leggermente diversa secondo quanto ideato circa 100 anni a.C. da Posidonio di Rodi (maestro di Cicerone). % % lang-it
% Proklos: jeden z epigonów matematyki greckiej
Czworokąt będzie równoległobokiem (kwadratem, podłużnym prostokątem, rombem, romboidem) albo nie (z parą boków równoległych, jako trapezium równoramienne lub ukośne albo bez niej -- trapezoidem). % % lang-pl
Wszystkie języki europejskie odziedziczą klasyfikację czworokątów po Proklosie... poza angielskim, gdzie znaczenie trapezoidu i trapezium odwróci słownik wydany przez Charlesa Huttona w 1795 roku. % % lang-pl
Porządek przywróci się około 1875 roku, ale amerykańskiego angielskiego już nikt nie uratuje. % % lang-pl
Un quadrilatero sarà un parallelogramma (quadrato, rettangolo allungato, rombo, romboide) oppure no (con una coppia di lati paralleli, come trapezio isoscele o obliquo, oppure senza, come trapezoide). % % lang-it
Tutte le lingue europee erediteranno la classificazione dei quadrilateri da Proclo... tranne l’inglese, dove il significato di trapezoid e trapezium sarà invertito da un dizionario pubblicato da Charles Hutton nel 1795. % % lang-it
L’ordine sarà ristabilito intorno al 1875, ma l’inglese americano non sarà più recuperato. % % lang-it
