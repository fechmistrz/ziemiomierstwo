\subsection{Ostrosłupy} % lang-pl
\subsection{Piramidi} % lang-it
\index{ostrosłup} % lang-pl
\index{piramide} % lang-it

\begin{definition}
[ostrosłup] % lang-pl
[piramide] % lang-it
    Wielościan, któreego wszystkie wierzchołki poza jednym leżą na jednej płaszczyźnie, nazywamy ostrosłupem. % lang-pl
    Un poliedro i cui vertici, tranne uno, giacciono tutti su uno stesso piano si chiama piramide. % lang-it
\end{definition}

W ostrosłupie, który ma co najmniej pięć wierzchołków, istnieje dokładnie jedna para wierzchołka i~ściany, na której leżą wszystkie pozostałe wierzchołki. % lang-pl
In una piramide con almeno cinque vertici esiste esattamente una coppia costituita da un vertice e da una faccia sulla quale giacciono tutti gli altri vertici. % lang-it
Nazywamy je wierzchołkiem i podstawą ostrosłupa. % lang-pl
Li chiamiamo vertice e base della piramide. % lang-it
(W ostrosłupie o czterech wierzchołkach, każda ściana może być podstawą). % lang-pl
(In una piramide con quattro vertici, ogni faccia può fungere da base). % lang-it
Ostrosłupy są szczególnymi przypadkami pryzmatoidów i mają się do stożków tak, jak graniastosłupy do walców. % lang-pl
Le piramidi sono casi particolari di prismoidi e stanno ai coni come i prismi stanno ai cilindri. % lang-it

Ściany boczne ostrosłupów są zawsze trójkątami. % lang-pl
Le facce laterali delle piramidi sono sempre triangoli. % lang-it
Wyróżniamy kilka szczególnych przypadków. % lang-pl
Distinguiamo alcuni casi particolari. % lang-it

\begin{definition}
[ostrosłup $n$-kątny] % lang-pl
[piramide a base $n$-gonale] % lang-it
    Ostrosłup, którego podstawa jest $n$-kątem, nazywamy ostrosłupem $n$-kątnym. % lang-pl
    Una piramide la cui base è un $n$-gono si chiama piramide a base $n$-gonale. % lang-it
\end{definition}

Ostrosłup trójkątny to inaczej czworościan. % lang-pl
Una piramide triangolare è semplicemente un tetraedro. % lang-it

\begin{definition}
[ostrosłup prosty] % lang-pl
[piramide retta] % lang-it
\index{ostrosłup!prosty}% % lang-pl
\index{piramide!retta}% % lang-it
    Ostrosłup, którego spodek wysokości pokrywa się ze środkiem okręgu opisanego na podstawie, nazywamy ostrosłupem prostym. % lang-pl
    Una piramide il cui piede dell'altezza coincide con il centro della circonferenza circoscritta alla base si chiama piramide retta. % lang-it
\end{definition}

Tak jest na przykład wtedy, kiedy wszystkie krawędzie boczne ostrosłupa albo wszystkie ściany boczne ostrosłupa tworzą z podstawą kąty równej miary. % lang-pl
Ciò accade, per esempio, quando tutti gli spigoli laterali oppure tutte le facce laterali formano con la base angoli della stessa ampiezza. % lang-it
Ale pojawią się też konkurencyjne definicje, takie jak: ostrosłup jest prosty, kiedy ma krawędzie boczne równej długości (i pochyły w przeciwnym przypadku). % lang-pl
Compariranno però anche definizioni concorrenti, secondo cui una piramide è retta quando ha gli spigoli laterali di uguale lunghezza (e obliqua nel caso contrario). % lang-it

\begin{definition}
[ostrosłup prawidłowy] % lang-pl
[piramide regolare] % lang-it
\index{ostrosłup!prawidłowy}% % lang-pl
\index{piramide!regolare}% % lang-it
    Ostrosłup prosty, którego podstawa jest wielokątem foremnym, nazywamy ostrosłupem prawidłowym. % lang-pl
    Una piramide retta la cui base è un poligono regolare si chiama piramide regolare. % lang-it
\end{definition}

Ostrosłup prawidłowy czworokątny nazywany jest czasami piramidą. % lang-pl
La piramide regolare a base quadrata viene talvolta chiamata semplicemente piramide. % lang-it
\index{piramida}% % lang-pl
\index{piramide}% % lang-it

\begin{definition}
[ostrosłup ścięty]% % lang-pl
[tronco di piramide]% % lang-it
\index{ostrosłup!ścięty}% % lang-pl
\index{piramide!tronco}% % lang-it
    Część ostrosłupa zawartą między podstawą a pewną płaszczyzną, która przecina ostrosłup, nazywamy ostrosłupem ściętym. % lang-pl
    La parte di una piramide compresa tra la base e un piano che la interseca si chiama tronco di piramide. % lang-it
\end{definition}

Jeśli płaszczyzna cięcia jest równoległa do podstawy, to bryłę nazywa się frustum, z łacińskiego \emph{kęs, kawałek}. % lang-pl
Se il piano di taglio è parallelo alla base, il solido viene chiamato \emph{frustum}, dal latino \emph{pezzo, frammento}. % lang-it
\index{frustum}%
Po polsku nie istnieje takie rozróżnienie: wymaga się, by płaszczyzna tnąca była zawsze równoległa do podstawy. % lang-pl
In polacco questa distinzione non esiste: si richiede che il piano di taglio sia sempre parallelo alla base. % lang-it
Eves \cite[s.4]{eves1_1972} napisze, że około 1850 lat przed Chrystusem znany będzie wzór na dokładną objętość frustrum o podstawach długości $a$, $b$ i wysokości $h$: % lang-pl
Eves \cite[p. 4]{eves1_1972} scriverà che intorno al 1850 a.C. era già nota la formula per il volume esatto di un frustum con basi di lato $a$, $b$ e altezza $h$: % lang-it
\begin{equation}
	V = \frac 1 3 h (a^2 + ab + b^2).
\end{equation}
Wzór pojawi się bez dowodu w papirusie moskiewskim, nazwanym tak, ponieważ jego pierwszym właścicielem spoza Egiptu będzie Władimir Goleniszczew, rosyjski egiptolog i kolekcjoner sztuki. % lang-pl
La formula comparirà senza dimostrazione nel Papiro di Mosca, così chiamato perché il suo primo proprietario al di fuori dell'Egitto sarà Vladimir Golenishchev, egittologo e collezionista d'arte russo. % lang-it
