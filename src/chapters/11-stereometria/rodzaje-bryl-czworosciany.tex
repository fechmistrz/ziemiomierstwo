\subsection{Czworościany} % tetrahedron % lang-pl
\subsection{Tetraedri} % tetrahedron % lang-it

W każdym czworościanie istnieje wierzchołek, przy którym trzy kąty płąskie są ostre. % https://www.deltami.edu.pl/2013/12/katy-trojscienne/ % lang-pl
In ogni tetraedro esiste un vertice nel quale i tre angoli piani sono acuti. % https://www.deltami.edu.pl/2013/12/katy-trojscienne/ % lang-it

\begin{proposition}
    Niech $ABCD$ będzie czworościanem. % lang-pl
    Wtedy następujące warunki są równoważne: % lang-pl
    Sia $ABCD$ un tetraedro. % lang-it
    Allora le seguenti condizioni sono equivalenti: % lang-it
    \begin{enumerate}
        \item Wszystkie ściany są przystające. % lang-pl
        \item Wszystkie ściany są trójkątami ostrokątnymi o takim samym promieniu okręgu opisanego. % lang-pl
        \item Suma kątów płaskich przy każdym wierzchołku wynosi $\pi$. % lang-pl
        \item Sumy kątów płaskich przy trzech dowolnych wierzchołkach wynosi $\pi$. % lang-pl
        \item Siatka czworościanu jest trójkątem ostrokątnym podzielonym na cztery przystające trójkąty. % lang-pl
        \item Kąty $\angle BAC$, $\angle ABD$, $\angle ACD$, $\angle BDC$ są równe. % lang-pl
        \item Przeciwległe krawędzie są równe. % lang-pl
        \item Trzy odcinki łączące środki przeciwległych krawędzi są parami prostopadłe. % lang-pl
        \item Wszystkie ściany mają równe pola. % lang-pl
        \item Rzut czworościanu $ABCD$ na dowolną płaszczyznę równoległą do dwóch przeciwległych krawędzi jest prostokątem. % lang-pl
        \item Każdy odcinek łączący środki przeciwległych krawędzi jest prostopadły do tych krawędzi. % lang-pl
        \item Tutte le facce sono congruenti. % lang-it
        \item Tutte le facce sono triangoli acutangoli con lo stesso raggio della circonferenza circoscritta. % lang-it
        \item La somma degli angoli piani in ciascun vertice è uguale a $\pi$. % lang-it
        \item Le somme degli angoli piani in tre vertici arbitrari sono uguali a $\pi$. % lang-it
        \item Lo sviluppo piano del tetraedro è un triangolo acutangolo suddiviso in quattro triangoli congruenti. % lang-it
        \item Gli angoli $\angle BAC$, $\angle ABD$, $\angle ACD$, $\angle BDC$ sono uguali. % lang-it
        \item Gli spigoli opposti sono uguali. % lang-it
        \item I tre segmenti che uniscono i punti medi degli spigoli opposti sono a due a due perpendicolari. % lang-it
        \item Tutte le facce hanno la stessa area. % lang-it
        \item La proiezione del tetraedro $ABCD$ su qualunque piano parallelo a due spigoli opposti è un rettangolo. % lang-it
        \item Ogni segmento che unisce i punti medi di due spigoli opposti è perpendicolare a tali spigoli. % lang-it
    \end{enumerate}
\end{proposition}

Dowód wszystkich 11 implikacji znajdziemy w artykulu Pompego, $\Delta_{94}^3$. % https://www.deltami.edu.pl/1994/03/o-czworoscianie-rownosciennym/ % lang-pl
La dimostrazione di tutte e undici le equivalenze si trova nell'articolo di Pompei, $\Delta_{94}^3$. % https://www.deltami.edu.pl/1994/03/o-czworoscianie-rownosciennym/ % lang-it

Czworościan, którego wysokości przecinają się w jednym punkcie, nazywamy ortocentrycznym. % lang-pl
Un tetraedro le cui altezze si incontrano in un punto si dice ortocentrico. % lang-it
W dziale Zadania w $\Delta_{00}^{8}$ (redaguje Łukasz Wiechecki) pojawią się trzy zadania o takich czworościanach: czworościan jest ortocentryczny wtedy i tylko wtedy, gdy każde dwie przeciwległe krawędzie są prostopadłe (M 925), wtedy i tylko wtedy, gdy sumy kwadratów przeciwległych krawędzi są równe (M 926) oraz wtedy i tylko wtedy, gdy odcinki łączące środki przeciwległych krawędzi mają równe długości (M 927); rozwiązania będą w tym samym numerze. % lang-pl
Nella rubrica Zadania di $\Delta_{00}^{8}$ (a cura di Łukasz Wiechecki) compariranno tre problemi su tali tetraedri: un tetraedro è ortocentrico se e solo se ogni coppia di spigoli opposti è perpendicolare (M 925), se e solo se le somme dei quadrati degli spigoli opposti sono uguali (M 926) e se e solo se i segmenti che uniscono i punti medi degli spigoli opposti hanno la stessa lunghezza (M 927); le soluzioni saranno nello stesso numero. % lang-it

Czworościan foremny ma trzy osie symetii: to proste przechodzące przez środki przeciwległych krawędzi. % https://www.deltami.edu.pl/1993/04/rozne-roznosci/ % lang-pl
Il tetraedro regolare possiede tre assi di simmetria: sono le rette passanti per i punti medi di coppie di spigoli opposti. % https://www.deltami.edu.pl/1993/04/rozne-roznosci/ % lang-it
