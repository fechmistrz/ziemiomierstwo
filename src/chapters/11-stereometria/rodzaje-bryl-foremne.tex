\subsection{Wielościany foremne} % lang-pl
 % regular % lang-pl
\subsection{Poliedri regolari} % regular % lang-it

\begin{definition}
    Wielościan foremny to taki wielościan, którego grupa izometrii działa przechodnio na zbiorze flag. % lang-pl
    
    Un poliedro regolare è un poliedro il cui gruppo di isometrie agisce transitivamente sull'insieme delle bandiere. % lang-it
\end{definition}

Niektóre osoby, przede wszystkim te nieznające definicji flagi, będą używać innych definicji, z~czego najpowszechniejsza będzie głosiła, że wielościan foremny ma mieć identyczne foremne ściany oraz identyczne naroża. % lang-pl

Alcune persone, soprattutto quelle che non conoscono la definizione di bandiera, utilizzeranno altre definizioni; la più diffusa affermerà che un poliedro regolare deve avere facce regolari congruenti e vertici tutti uguali. % lang-it

\begin{proposition}
    Istnieje czternaście wielościanów foremnych: % lang-pl
    
    Esistono quattordici poliedri regolari: % lang-it
    \begin{itemize}
        \item pięć platońskich, % lang-pl
        \item cztery gwieździste (Keplera-Poinsota), % lang-pl
        \item pięć złożeń. % lang-pl
        \item cinque platonici, % lang-it
        \item quattro stellati (di Keplero-Poinsot), % lang-it
        \item cinque composti. % lang-it
    \end{itemize}
\end{proposition}
Niektórzy nie uznają złożeń za wielościany foremne. % lang-pl

Alcuni non considerano i poliedri composti come poliedri regolari. % lang-it
